Methodology

How we test and score commercial software

Most "best CRM" content ranks tools by feature count. We think that's the wrong lens now. The question worth answering in 2026 isn't "does this tool have an AI feature" (nearly all of them do) it's "can an autonomous agent actually act inside this system without a human re keying half of it."

What we actually check

  1. Data model, not marketing copy. Can the underlying object model represent an agent initiated action as a first class, auditable event, or does "AI" mean a chat widget bolted on top of a static record?
  2. Real, documented agent access. Does the vendor publish an actual interface an external agent can call (an MCP server, a scoped API) or is the "agentic" claim marketing language with no technical detail behind it? We say so explicitly when we can't verify a claim.
  3. Permission scoping. Where an agent interface exists, is it genuinely scoped (read vs. write, per object, role based) or all or nothing access dressed up as "AI ready"?
  4. Pricing and packaging fit. Does the vendor's own pricing model assume seat based usage, a red flag for a tool meant to support consumption or outcome based commercial models, or does it flex with usage and agent driven activity?

Why some vendors have no "Try it free" button

A genuine share of the vendors we review (mostly enterprise, sales led tools like Gong, Vendavo, or Outreach) do not run a public affiliate or referral program. We include them anyway when they're a real answer to "what's the best tool in this category," and we mark every single one clearly: an affiliate tag when a link is (or will be) a tracked, commissioned link, and an information tag with a plain, untracked link when it isn't. Inclusion in this list isn't for sale, and it never determines the score a tool gets.

Who writes this

The Agentic Stack is written by the team behind FR Advisory's Agentic Commercial Model, a diagnostic framework used to benchmark how ready a commercial organisation (not just its tools) is for the agentic era. That's the lens every review here is written through.
