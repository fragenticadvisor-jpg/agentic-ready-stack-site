Category 10 · Finance & Operations

Accounting

Small business accounting sits outside the go-to-market stack this site started with, but it's a category almost every growing company eventually touches, and unusually for back office software, two of the three vendors here have gone further than most of the GTM stack on agent access: both Xero and QuickBooks Online publish their own open source MCP servers with real write scopes, not just an in-app copilot.

Xero is a live, tracked affiliate relationship today. We're in the process of applying to FreshBooks' affiliate program. QuickBooks Online runs a referral program but it requires a US-registered business with a US EIN and US bank account, which we don't have, so that link is untracked. See our full disclosure.
01QuickBooks Online
High: native MCP server Affiliate program (US entities only)

Small business accounting: from $19/mo promo (~$38/mo regular) · quickbooks.intuit.com

Intuit's cloud accounting platform and the dominant small business accounting product in the US market, spanning basic bookkeeping through project tracking, inventory, and advanced reporting at the top tier. It's the default most US accountants and bookkeepers are trained on.

Agentic angle: Intuit publishes an official MCP server under its own GitHub org (intuit/quickbooks-online-mcp-server): 144+ tools across 29 entity types with full create, read, update, and delete access, individually toggleable via environment flags, plus 11 financial reports. It's real, vendor published, and substantive, but it lives on GitHub rather than Intuit's primary developer documentation portal, and even Intuit's own developer forum has an unanswered thread asking whether it exists. Verified against vendor documentation, 24 Sept 2026.
Visit QuickBooks Online →
02Xero
High: native MCP server Affiliate program

Small business accounting: from $25/mo · xero.com

Cloud accounting software aimed at small businesses and the accounting and bookkeeping firms that serve them, with particular strength outside the US in New Zealand, Australia, and the UK. Covers invoicing, bank reconciliation, payroll, inventory, and multi-currency accounting.

Agentic angle: Xero publishes an official MCP server under its own GitHub org (XeroAPI/xero-mcp-server): documented read and write tools spanning contacts, chart of accounts, invoices, bank transactions, and payroll, gated by granular OAuth2 scopes. Same pattern as QuickBooks: real vendor published code with a documented tool list, just not yet surfaced on Xero's primary developer docs site. Verified against vendor documentation, 24 Sept 2026.

03FreshBooks
Medium: documented API, no first-party MCP Affiliate program

Invoicing led accounting for freelancers & small teams: from $23/mo (lower promo pricing) · freshbooks.com

Invoicing led accounting software aimed at freelancers, solopreneurs, and small service based businesses such as consultants and agencies, rather than full bookkeeping depth for larger SMBs. Emphasizes client facing invoicing, time tracking, and expense capture over general ledger depth.

Agentic angle: FreshBooks maintains a documented, conventional REST API with write endpoints, but publishes no first party MCP server or agent specific interface itself. Every MCP server we found for it (StackOne, Composio, Zapier, an independent GitHub project) is a third party wrapper built on top of that existing API, not something FreshBooks built or documents. Verified against vendor documentation, 24 Sept 2026.
