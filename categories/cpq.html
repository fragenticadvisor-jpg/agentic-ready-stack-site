Category 05 · Layer 3 — Pricing and Packaging

CPQ

Configure-price-quote is the layer that decides whether an agent can actually close a deal, not just chat about one. We looked for a real, documented interface — ideally MCP — that lets an agent generate and send a priced quote on its own, versus a human still assembling the document.

Some links below are affiliate links — see our full disclosure. Where a vendor has no public affiliate program, we link straight to their site with no tracking and say so.
01PandaDoc
High — native MCP server Affiliate program

Document automation, proposals & CPQ — free plan, paid from $19/seat/mo · pandadoc.com

Document automation software for proposals, quotes, contracts, and e-sign with lightweight CPQ, positioning itself directly against DocuSign on agent-readiness. The clearest combination in this category of documented agentic architecture and a real, tiered affiliate program.

Agentic angle: A native MCP server lets an agent execute a full workflow from a single natural-language instruction — e.g. "create a proposal for Acme at $25,000/year and send for signature" — the strongest, most concretely demonstrated example we found in this whole comparison.
