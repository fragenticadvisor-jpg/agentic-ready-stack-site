Category 02 · Layer 2 — Go-to-Market

Marketing Automation

Email, SMS, and lifecycle marketing is where agent-executed work is furthest along in practice — several vendors here ship a documented, permissioned interface an external AI agent can actually call, not just an in-app assistant.

Some links below are affiliate links — see our full disclosure. Where a vendor has no public affiliate program, we link straight to their site with no tracking and say so.
01ActiveCampaign
High — native MCP server Affiliate program

Marketing automation — from ~$15/mo · activecampaign.com

The strongest pure automation engine here for complex branching journeys, with a solid API. Agentic behaviour isn't native — you'll be building it on top via API or Zapier/Make rather than getting it out of the box.

Agentic angle: ActiveCampaign documents a first-party remote MCP server, with a per-account URL generated under Settings → Developer, that explicitly supports writes: creating and updating contacts, lists, tags and custom fields, moving contacts through automations, and creating and sending campaigns. Rather more than the rule-based automation layer we first took it for. Verified against vendor documentation, 21 Aug 2026.

02Klaviyo
High — documented MCP No self-serve affiliate link

Ecommerce marketing automation / CDP — from ~$20/mo, free tier available · klaviyo.com

Built around a unified customer profile for ecommerce and DTC brands, with deep Shopify integration and revenue-attribution reporting. Pricing scales with contact volume, with a genuinely usable free tier.

Agentic angle: Ships an official MCP server exposing roughly 40 tools across campaigns, profiles, segments, and flows, with a read-only mode and scoped, role-based permissions — a real externally-actionable agent interface, documented and live.
Visit Klaviyo → Runs an agency/reseller partner program, not a public pay-per-referral affiliate link.
03Customer.io
High — documented MCP No self-serve affiliate link

Behavioural / event-triggered messaging — from ~$100/mo · customer.io

Built on an object-based customer data pipeline for product-led teams that need event-triggered messaging rather than pure ecommerce campaign sends. No meaningful free tier, but a 12-month startup grant exists.

Agentic angle: A documented external-agent MCP server with granular OAuth-style scopes (read, read:sensitive, write, write:live, configure), separate from its in-app chat assistant — one of the more rigorously permissioned agent interfaces we found in any category.
Visit Customer.io → Solutions/technology partner programs exist; no standalone public affiliate program found.
04Semrush
High — MCP server, read-scoped Affiliate program

SEO & content research — from ~$139/mo · semrush.com

Not a CRM or automation platform, but essential infrastructure for any content-driven demand-gen motion, including this site. Its API is well-documented enough for an agent to pull keyword and competitive data programmatically rather than a human exporting CSVs.

Agentic angle: A mature, well-scoped API built for programmatic pulls — the kind of data layer an agent-driven content pipeline can actually run on. Semrush also publishes a first-party MCP server over OAuth 2.0 or API key — but its tools are read-only by design; the scoped write endpoints sit separately on the v4 Projects REST API. Verified against vendor documentation, 21 Aug 2026.

05ClickFunnels
Medium — MCP in technical preview Affiliate program

Funnel / landing page builder — from ~$81/mo · clickfunnels.com

Overkill for most B2B commercial teams, but a legitimate pick if your motion runs through high-conversion landing pages and checkout flows rather than a traditional CRM pipeline. One of the more generous affiliate programs in this whole comparison.

Agentic angle: ClickFunnels documents its own MCP server at agents.myclickfunnels.com/mcp, using OAuth with a selectable read-only or full-access permission level; full access creates and updates funnels, pages, contacts, products and courses. It is explicitly a Labs technical preview, so treat it as real but early. Verified against vendor documentation, 21 Aug 2026.
