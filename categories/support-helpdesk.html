Category 12 · Customer Operations

Support & Helpdesk

This is a different layer from our existing Customer Success category: that one covers retention and health score tools like Gainsight, this one covers the ticketing and support inbox tools support teams actually work out of all day. It's also a useful contrast case: the vendor with the best affiliate deal isn't the one with the best agent access, and the one with the best agent access has no self serve affiliate program at all.

We're in the process of applying to Help Scout's and Zendesk's affiliate programs. Intercom has no public self serve affiliate program open to a site like this, so that link is untracked. See our full disclosure.
01Intercom
High: documented MCP No affiliate program

AI-first customer messaging & support: from $29/seat/mo + $0.99/AI resolution · intercom.com

A customer messaging and support platform combining a shared inbox, help center, and an AI agent ("Fin") for automated resolutions, sold mainly to mid market and enterprise teams that want AI assisted deflection layered on live chat and email. Pricing is per seat plus consumption based AI fees.

Agentic angle: Intercom hosts an official, Intercom run remote MCP server documented at developers.intercom.com/docs/guides/mcp: 14 tools including genuine write access (create_article, update_article, add_internal_note) gated by four OAuth style permission scopes. This is real read and write agent access, not just an embedded chatbot, and the strongest agentic evidence in this category. Verified against vendor documentation, 24 Sept 2026.
Visit Intercom →
02Help Scout
Medium: MCP in technical preview Affiliate program

Email-first shared inbox helpdesk: free plan available, from $25/user/mo · helpscout.com

A shared inbox helpdesk for small to mid size support teams that want an email centric, lower complexity alternative to Zendesk or Intercom, with a generous free tier and a bundled public knowledge base ("Docs") on every plan.

Agentic angle: Help Scout shipped a first party MCP server backed by real technical documentation, not just an announcement post: a setup guide for connecting Claude, ChatGPT, or Cursor to search conversations and pull reports, scoped to each teammate's own login. Capability is currently read only. Help Scout's own post says drafting replies and adding internal notes are planned but not yet released, which is why this sits at "technical preview" rather than the top tier. Verified against vendor documentation, 24 Sept 2026.

03Zendesk
Limited: MCP announced, not documented Affiliate program

Omnichannel support suite: from $19/agent/mo (Suite from $55/agent/mo) · zendesk.com

A long established, broad customer service platform spanning ticketing, omnichannel messaging, a knowledge base, and AI copilot tooling, priced per agent seat across tiered plans. Generally positioned as the feature dense incumbent above Help Scout.

Agentic angle: Zendesk's own docs describe it primarily as an MCP client: its action flow builder connects out to third party MCP servers, the opposite of what we're testing for. One line in that same article claims Zendesk "can also act as an MCP server," but no scope list, endpoint reference, or spec backs that claim up, and the actual "MCP Server" app in Zendesk's marketplace is built by a third party (Swifteq), not Zendesk itself. This is exactly the announced but undocumented pattern this site exists to flag. Verified against vendor documentation, 24 Sept 2026.
