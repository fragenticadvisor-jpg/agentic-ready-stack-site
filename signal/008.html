01Layer 3 · Pricing & Packaging Strategy

PROS's new Kairos platform cites MCP under the hood. The only ‘Developers’ link still leads to a partner marketing page.

On Oct 12, 2026, PROS launched PROS Kairos, a new “agentic airline retailing platform” combining its pricing engine, airline data and six named agents (Offer Marketing Agent, Offer Agent, Group Sales Agent, Pricing Agent, Demand Agent, plus a Fare Finder Agent aimed at travelers) in one workspace built on a Databricks data foundation. PROS's own press release states that its “Agent Orchestrator is designed to coordinate specialized agents through open-source Model Context Protocol (MCP) connections” — the first time this registry has found PROS naming MCP in its own materials. The Kairos product page frames every one of those agents as first party: “The agents are built directly in the PROS Platform.” Its “Developers” navigation link leads not to an API reference or MCP spec but to the AirModules partner program page, a marketing page with no auth method, scopes or endpoints published.

Why it matters: PROS already sits at “none found” on MCP in this registry, for exactly the reason the Kairos launch reconfirms: an internal MCP connection PROS uses to wire its own six agents together is a real architecture choice, but it isn't the same claim as a documented MCP server an outside agent, yours, can authenticate against. That's the same first-party-agent-versus-external-interface gap we flagged in CaptivateIQ's “Coming Soon” page and DealHub's missed October deadline; PROS's version is more credible, because the agents described are shipping product rather than a roadmap slide, but it still leaves Pricing & Packaging Strategy at one vendor, Zilliant, with a documented, if read only, external agent interface. We're re-dating PROS's row to note the new framing without changing its grade: “none found” on MCP remains the accurate read until there's an endpoint to point to.

Source: PROS: PROS Launches PROS Kairos · PROS: AI Agents · PROS: AirModules partner program (the Developers link's actual target)

Registry moves

One row re-dates this week, to 3 November 2026, with no pill-grade change. PROS's row is re-dated to note the Oct 12, 2026 launch of PROS Kairos, whose own press release is the first PROS material to name MCP — used, by PROS's account, to orchestrate its own first-party agents rather than to expose an interface external agents can call. The buildwith.pros.com and marketplace.pros.com developer reference and the real write endpoints on the eCommerce Quote API, both noted in our Oct 5 check, are unchanged and remain the only documented surface an outside integration can build against.

No aggregate figures move: the registry still shows 27 of 43 vendors publishing an official MCP server and 33 of 43 documenting agent write access. The single zero-interface category (Sales Compensation & Incentive Management) is unchanged.
